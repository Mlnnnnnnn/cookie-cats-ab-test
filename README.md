# A/B-тест в игре Cookie Cats

## Задача
В мобильной игре Cookie Cats есть "ворота": на определённом уровне игрок должен
подождать или заплатить, чтобы играть дальше. Разработчики проверили, где лучше
поставить ворота: на 30-м уровне или на 40-м.

## Данные
90189 игроков. Для каждого известно, вернулся ли он в игру через 1 и через 7 дней
и сколько раундов сыграл.

Датасет: https://www.kaggle.com/datasets/yufengsui/mobile-games-ab-testing

## Результат
Через 7 дней в игру вернулись 19.0% игроков с воротами на 30-м уровне
и 18.2% с воротами на 40-м. Разница статистически значима.

**Вывод: ворота лучше оставить на 30-м уровне.**
